# Law Website Next.js

A modern and responsive law firm website built with Next.js and Tailwind CSS.

## 🚀 Technologies

- Next.js 16
- React
- JavaScript
- Tailwind CSS
- App Router

## 📌 Features

- Responsive design for all devices
- Modern law firm landing page
- Reusable components architecture
- Dynamic routing
- Blog pages
- Lawyers pages
- Services pages
- Tailwind CSS styling
- Optimized images and fonts
